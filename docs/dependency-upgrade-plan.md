# План обновления зависимостей

Базовая проверка: `npm outdated`, `npm audit`, затем отдельный pull/commit на одну
группу зависимостей. После каждой группы обязательны `npm test`, `npm run lint`,
`npx tsc --noEmit`, `npm run build` и smoke-тест входа, доски, задачи и Wiki.

## P0 — безопасность

Выполнено 26 июля 2026:

1. Next.js и `eslint-config-next` обновлены с 16.1.4 до 16.2.12.
2. React и React DOM обновлены синхронно с 19.2.3 до 19.2.8.
3. Prisma-пакеты обновлены с 7.3.0 до 7.9.0.
4. MDXEditor с неисправленным advisory в `js-yaml` заменён на
   `@uiw/react-md-editor`.

На дату обновления npm всё ещё помечает последний стабильный Next.js 16.2.12 и
Prisma 7.9.0 как уязвимые, но исправленных стабильных версий не предлагает.
Не откатывать их на предложенные `npm audit fix --force` старые версии. Проверять
upstream еженедельно и обновить сразу после выхода исправленного стабильного
релиза.

Критерий готовности следующего шага: исчезли direct advisories Next.js и Prisma,
сборка и Server Actions работают.

## P1 — Prisma

Пакеты уже синхронно обновлены до 7.9.0. После следующего исправленного релиза
обновлять одним набором `prisma`, `@prisma/client` и `@prisma/adapter-pg`.
Проверить `prisma validate`, `prisma generate`, применение миграций на пустой БД
и на копии текущей схемы.

Критерий готовности: версии трёх пакетов совпадают, миграции идемпотентны, CRUD
задач и Wiki проходит smoke-тест.

## P2 — UI и инструменты

1. Обновить Tailwind/PostCSS, TypeScript, ESLint и типы Node/React.
2. Обновить dnd-kit, Headless UI, Framer Motion и MDXEditor отдельными группами.
3. Проверить drag-and-drop доски и rich-text/Markdown режимы редактора вручную.

## P3 — автоматизация

1. Подключить Renovate или Dependabot с недельным расписанием.
2. Группировать только патч-обновления совместимых пакетов.
3. Добавить CI-проверки Prisma, типов, lint, тестов, production build и audit.
4. Ежемесячно удалять неиспользуемые прямые зависимости после `npm ls` и поиска
   импортов.
