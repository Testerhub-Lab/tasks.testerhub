## Найденные расхождения инфраструктуры

1. В исходном init SQL публикация `wiki_pages` включала шесть полей review,
   отсутствующих в клиентской Zero-схеме. Фактический production уже исключает
   их. Исправлен только список колонок публикации в `infra/zero-stage2/schema.sql`;
   поля в таблице и серверное согласование сохранены. Все 16 локальных списков
   колонок сверены с production. Тест публикации проходит.
2. В production у `pulsar_app` нет USAGE на `pulsar_production_0`.
   При том же разграничении прав локальный `/zero` читает данные, но запись
   через Zero 1.8 mutator падает на записи acknowledgement в служебные таблицы.
   Локально выданы только USAGE на `pulsar_design_local_0`, SELECT/INSERT/UPDATE
   на `clients`, INSERT/DELETE на `mutations`.
   Повторная запись через Zero успешно сохранилась в БД.
   Production-права не менялись; это отдельная инфраструктурная проблема,
   которую нельзя считать устранённой на проде.
3. LocalStack использует секрет `test` для проверки presigned URL незарегистрированных
   ключей. Начальная случайная локальная S3-пара давала SignatureDoesNotMatch.
   Исправлена только локальная конфигурация. Код загрузки и проверка подписи сохранены.
