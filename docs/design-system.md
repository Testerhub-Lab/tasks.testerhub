# Pulsar UI

Основные токены и общие стили находятся в `src/app/globals.css`.
Текущий визуальный эталон и UI-kit: `/prototypes/pulsar/#kit`.
Лендинг: `/welcome`. Входная страница `/` по-прежнему ведёт на доску.

## Палитра и поверхности

| Токен | Назначение | Тёмная тема |
| --- | --- | --- |
| `--surface-0` | Фон пространства | `#0b1013` |
| `--surface-1` | Основные поверхности и Markdown | `#12191d` |
| `--surface-2` | Приподнятые элементы | `#1b242a` |
| `--surface-popover` | Меню, поповеры, списки выбора, уведомления | `#1a242b` |
| `--surface-dialog` | Модальные окна и панели задач | `#151d22` |
| `--primary` | Серебряный акцент | `#c5d9e4` |
| `--text` | Основной текст | `#e6edf0` |
| `--muted` | Вторичный текст | `#a0adb5` |
| `--text-subtle` | Подписи и метаданные | `#75858e` |

Границы: `--sep` и `--sep-strong`. Фокус: `--ring`.
Подложка модальных окон: `--overlay`. Тени: `--shadow-popover` и `--shadow-dialog`.
Скругления: `--radius-sm`, `--radius-md`, `--radius-lg`.
Аватары пользователя и рабочего пространства круглые; аватары проектов могут быть квадратными.

Для новых элементов используйте общие `Button`, `Input`, `Select`, `Textarea`, `Card`
и эти токены. Выпадающие элементы в порталах наследуют токены от `:root`.
Tailwind-палитры slate/cyan и отдельные семантические оттенки связаны с Pulsar через `@theme inline`.
Статусы, приоритеты, ошибки и предупреждения сохраняют свои различимые цвета.

## Компоновка и поведение

Шапка компактная: контекст проекта, Board/List, поиск, небольшая кнопка создания и аккаунт.
На узких экранах боковая навигация открывается кнопкой; канбан прокручивается горизонтально.
Меню и карточки не требуют анимации или дополнительного UI-фреймворка.
Markdown-редактор, включая полноэкранный режим, использует общие поверхности.

Внешний вид отделён от существующих обработчиков: URL-фильтры, сохранение вида,
DnD с оптимистическими обновлениями, права доступа, загрузка файлов, шаблон бага,
Create more, Wiki-черновики и клавиатурные сценарии остаются в своих компонентах.
