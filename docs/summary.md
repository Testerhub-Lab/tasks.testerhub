# Tasks Tracker Project Summary

## Что сделано:

1. **Инициализация проекта**:
   - Создан проект на основе Next.js 14+ с TypeScript, Tailwind CSS и Prisma ORM.

2. **Настройка Prisma**:
   - Добавлена схема базы данных в `prisma/schema.prisma`.
   - Создан файл `prisma.config.ts` для конфигурации Prisma 7.
   - Выполнены миграции базы данных.

3. **Добавлены базовые страницы и стили**:
   - Главная страница (`src/app/page.tsx`) с приветственным сообщением.
   - Глобальные стили (`src/app/globals.css`) с настройкой тёмной темы по умолчанию.

4. **Docker и CI/CD**:
   - Создан `Dockerfile` для сборки и запуска приложения.
   - Добавлена конфигурация GitHub Actions (`.github/workflows/deploy.yml`) для автоматического деплоя.

5. **Локальный запуск**:
   - Инструкции по запуску проекта локально без Docker.

## Следующие шаги:
- Реализация функционала (форма создания задач, Kanban-доска, комментарии и т.д.).
- Интеграция с Telegram для уведомлений.
- Добавление аутентификации через NextAuth.js.
- Локализация (русский и английский языки).
- Оптимизация производительности и адаптивности.
