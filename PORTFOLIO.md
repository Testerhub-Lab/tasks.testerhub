# Portfolio Summary (for FL.ru)

## Project name
TesterHub Tasks — Система управления задачами и багами

## One-liner (1 sentence)
Современный веб-трекер задач с Kanban-доской, Drag & Drop интерфейсом, гибкой системой ролей и SSO-авторизацией, разработанный на Next.js 16 и PostgreSQL.

## Business value (2–3 bullets)
- **Ускоряет работу команд** — интуитивный UI с Kanban-доской и мгновенным изменением статусов через Drag & Drop
- **Снижает порог входа** — гостевой режим позволяет внешним пользователям создавать задачи без регистрации (контролируется настройками проекта)
- **Готов к интеграции** — SSO-авторизация через внешние системы, REST API для загрузки файлов, масштабируемая архитектура

## Key features (6–10 bullets)
- 📋 **Kanban-доска** с Drag & Drop перемещением задач между статусами (7 статусов: New → Todo → In Progress → Testing → Done)
- 📝 **Backlog** — список входящих задач для сортировки
- 🔍 **Фильтры и поиск** по статусу, приоритету, тегам, проекту с URL-персистенцией
- 📎 **Загрузка файлов** до 25 MB, поддержка множественной загрузки и Drag & Drop
- 💬 **Комментарии** с optimistic updates (мгновенное отображение до подтверждения сервером)
- 🔐 **SSO-авторизация** через внешний сервис с управлением сессиями
- 👥 **Система ролей** (Guest / User / Admin) с гибким контролем доступа на уровне проекта
- 📁 **Multi-project** — поддержка нескольких проектов с автоматической генерацией ключей (PROJECT-123)
- ✏️ **Inline-редактирование** заголовка и описания задачи
- ⌨️ **Горячие клавиши** — Cmd+K (поиск), Cmd+Enter (отправка), Esc (отмена)

## Tech stack
**Frontend:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Framer Motion, @dnd-kit (Drag & Drop), @headlessui/react

**Backend:** Next.js Server Actions, API Routes, Prisma ORM 7

**DB:** PostgreSQL

**Infra/Deploy:** Docker, Node.js 18, GitHub Actions (CI/CD)

**Integrations:** SSO-авторизация через внешний сервис (TesterHub), REST API для работы с файлами

# FL.ru description

**Разработка системы управления задачами (Issue Tracker) с нуля**

Современный веб-трекер задач, спроектированный для команд разработки и QA. Интуитивный интерфейс, быстрая навигация, гибкая система прав.

**Ключевые возможности:**

• Kanban-доска с Drag & Drop — перетаскивание задач между статусами (New, Todo, In Progress, Testing, Done)
• Backlog и табличный вид — удобная сортировка входящих задач
• Фильтры и поиск — по статусу, приоритету, тегам, проекту
• Комментарии к задачам — с мгновенным отображением (optimistic UI)
• Загрузка файлов — множественная загрузка, Drag & Drop, до 25 MB
• Multi-project — несколько проектов, автоматические ключи (PROJECT-123)
• Inline-редактирование — заголовок и описание правятся прямо на странице
• SSO-авторизация — интеграция с внешним сервисом, управление сессиями
• Роли и права — Guest / User / Admin с настройкой на уровне проекта
• Горячие клавиши — быстрая навигация без мыши

**Технологии:**

• Frontend: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion
• Backend: Next.js Server Actions, API Routes, Prisma ORM
• База данных: PostgreSQL
• Инфраструктура: Docker, Node.js 18, GitHub Actions
• Интеграции: SSO, REST API
